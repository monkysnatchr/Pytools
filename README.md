Welcome to Pytools! 
As the name suggests, this app consists of many tools, coded in Python!
The tools are, as followed:


**Random Tools**

Random Number Generator — Generate random integers within a specified minimum and maximum, with reroll support.

Dice Roller — Roll dice using notation such as 2d6 or 1d20, displaying individual rolls and their total.

Coin Flip — Randomly flip a coin to get heads or tails.

Random Choice Picker — Pick a random item from a comma-separated list.

Password Generator — Generate random passwords with a customizable length using Python's secure random generator.

UUID Generator — Generate unique UUIDs.


**Math Tools**

Percentage Calculator — Calculate a percentage of a given value.

Prime Number Checker — Check whether an integer is a prime number.


**Text & Data Tools**

Text Counter — Count words, characters, and lines.

Case Converter — Convert text to uppercase, lowercase, title case, or swap case.

Base64 Encoder/Decoder — Encode text to Base64 or decode Base64 text.

JSON Formatter — Validate JSON input and display it in a readable, indented format.


**File Tools**

SHA-256 File Hasher — Calculate a file's SHA-256 hash.

Folder Statistics — Count files, calculate total file size, and summarize file extensions.

File Organizer — Automatically sort files into folders based on their extensions.


**Network Tools**

IP Address Checker — Validate IPv4 and IPv6 addresses and display address propertiesountdown for a specified number of seconds.

Current Date & Time — Display the current local date and time.
